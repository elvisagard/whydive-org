# WhyDive Whitepaper Roadmap

## Governing Document for Future Framework Publications

June 2026

## Purpose

This document defines the planned whitepaper ecosystem for WhyDive and its domain expressions.

It exists to:

- Prevent architectural drift
- Clarify document hierarchy
- Define audience by document
- Prevent duplication
- Guide future development

Every future whitepaper should be interpreted through this roadmap.

## Governing Principle

WhyDive exists to strengthen judgment.

It develops the forms of reasoning that shape judgment because judgment shapes decisions, and decisions shape the lives of individuals, communities, and societies.

All future whitepapers are expressions of this principle.

## Anti-Drift Rule

Before writing any future document, answer:

1. Which entity is speaking?
2. Which audience is being addressed?
3. What question is being answered?
4. What layer of the hierarchy does this document belong to?

If those questions cannot be answered clearly, the document should not be written until they are.

## Governing Statement

WhyDive is not a collection of products.

It is a framework concerned with how human beings move from evidence to action.

The whitepaper ecosystem exists to explore that movement from multiple levels:

- Philosophical
- Architectural
- Educational
- Disciplinary
- Societal

Every future document should contribute to that larger mission.
